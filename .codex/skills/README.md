# Repo Skills

This repository includes a small set of local Codex skills under `.codex/skills`.

## Included Skills

- `engineering-standards`
  - Base anti-slop coding standards for all changes.
- `frontend-architecture`
  - React, component boundary, accessibility, and UI structure guidance.
- `project-structure`
  - File placement, refactoring, and repo organization rules.
- `testing-standards`
  - Behavior-focused testing guidance.

## Recommended Usage

- Apply `engineering-standards` by default for all coding tasks.
- Add `frontend-architecture` for UI and React work.
- Add `project-structure` when creating or moving files.
- Add `testing-standards` when changing tests or fixing regressions.

## Why Split Them

Focused skills are easier for agents to apply consistently than one large standards document. Shared rules stay global, while project-specific decisions remain discoverable in the relevant skill.
